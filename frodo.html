About This Course

Web Design and Development introduces students to the basic concepts of creating websites and web-based applications.

Students will learn how to structure web pages using HTML and later improve them using CSS, JavaScript, server-side scripting, and databases.

Main Topics Covered

  • Introduction to the World Wide Web
  • HTML document structure
  • HTML tags and elements
  • Forms and tables
  • Static and dynamic web pages
  • Client-side and server-side scripting

Basic Technologies Used in Web Development

  1. HTML for structure
  2. CSS for design and layout
  3. JavaScript for interactivity
  4. Server-side language for processing
  5. Database for storing information
